<h3>📕About📕</h3>

Readme is the first what people see after clicking on your github repo, it's like the face of your project. Therefore if people see captivating and professional project structure then they are more likely to dive into your repo, put star, clone, etc. In addition well done project structure really increases productivity and efficiency of contributing. Eventually amazing repo out look gives gigantic boost to contributing and utilizing experience. That's why I want to share with you experienced and breathtaking readme, templates and repo structure. No more need to manually configuring every repo just copy and paste with minimum of changes.

> [!NOTE]
> Before creation of this project, I'd done a massive research across all readmes on github to create a real work of art.

---

<h3>🏁Getting Started🏁</h3>

Start with cloning repo `git clone https://github.com/ByteCorum/amazing-repo-template.git`.

Then navigate to template directory `cd template`.

In there u should insert your repo info inside `README.md` file. In `.github` directory set up `FUNDING.yml` and `CODEOWNERS`. Finally if you wish remove placeholder text in `docs` dir in `ChangeLog.md` and `Todo.md` files

> [!TIP]
> Don't forget to fill contacts and support fields in `README.md`

---

<h3>🌀Usage🌀</h3>

When every thing is filled and ready to go. Just create repo than copy everything from `template` directory into your repo and push to github.
